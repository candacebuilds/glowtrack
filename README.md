# ✨ GlowTrack

A beginner-friendly Python self-care and habit tracking console application.

GlowTrack was created as a learning project while studying computer science and Python programming fundamentals. The goal of the project is to combine programming practice with a calming, supportive self-care experience.

---

# 🌸 Features

## Mood Tracking

Users can:

* log their daily mood
* receive supportive responses based on mood selection
* practice emotional self-awareness through simple daily check-ins

Supported moods currently include:

* happy ✨
* sad 💖
* stressed 🌸
* tired 🌙

---

## Daily Affirmations

GlowTrack includes a random affirmation generator using Python lists and the `random` module.

Each time the user selects the affirmation option, the program displays a different motivational message.

Example affirmations:

* "You are growing every day 🌱"
* "Small progress still counts ✨"
* "You are stronger than you think 💖"

## Repeating Menu System

GlowTrack now remains active after completing an action, allowing users to continue using the application without restarting it.

The application loops back to the main menu after each completed task and only exits when the user selects the Exit option.

This feature improves the user experience and better simulates how a real application behaves.
